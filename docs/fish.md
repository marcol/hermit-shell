# Fish

## Aliases

- `l` - colorized list files
- `la` - colorizedlist all files including hidden files
- `lg` - colorized git status
- `ll` - colorized list files in long format with human-readable sizes
- `lt` - colorized tree view of files and directories
- `pip` - alias for pipx
- `pubkey` - copy public ssh key
- `py` - alias for python3
- `reload` - reload zsh configuration
- `update` - update brew and node
- `vim` - alias for nvim
